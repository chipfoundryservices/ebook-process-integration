# Appendix A: Process Integration Glossary

- **Back-End-of-Line (BEOL):** The sequence of fabrication steps creating the multi-tier metal interconnect wiring grid (M0 to Top Metal).
- **Backside Power Delivery Network (BSPDN):** Integration architecture relocating the power grid to the rear of the thinned wafer to eliminate IR drop.
- **Buried Power Rail (BPR):** Conductive metal rail embedded beneath active transistor channels to route power from backside vias.
- **Contacted Poly Pitch (CPP):** The center-to-center distance between adjacent transistor gates, defining front-end logic density.
- **DTCO (Design-Technology Co-Optimization):** Cooperative optimization between physical layout design and process technology knobs.
- **Front-End-of-Line (FEOL):** The initial sequence of fab steps forming isolated single-crystal transistors on the silicon substrate.
- **High-k Metal Gate (HKMG):** Transistor gate stack comprising an atomic layer dielectric ($\text{HfO}_2$) and workfunction metal layers.
- **Middle-of-Line (MOL):** The intermediate interface layer connecting transistor source/drain and gate electrodes to the first metal interconnect layer.
- **Nano-Through-Silicon Via (nTSV):** Sub-100nm vertical via connecting backside power rails through the thinned silicon substrate.
- **Replacement Metal Gate (RMG):** Gate-last integration flow where sacrificial polysilicon is removed after high-temperature source/drain anneals.
- **Self-Aligned Contact (SAC):** Contact via etched using dielectric hardmask selectivity to prevent shorting against adjacent gate electrodes.
- **Single Diffusion Break (SDB):** Isolation scheme using a single etched dielectric trench to separate adjacent standard cells.
